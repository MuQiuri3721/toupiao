# 🎤 校园十佳歌手 · 实时投票系统

零依赖的局域网/公网实时投票系统：学生手机扫码投票，老师大屏实时看排名，自带演示模式。只需电脑装有 Node.js，**无需 `npm install`**。

> 详细操作手册见 [使用说明.md](使用说明.md)

## 快速开始

```bash
node server.js        # 或双击 启动投票系统.bat
```

| 页面 | 地址 | 用途 |
|------|------|------|
| 投票页 | http://localhost:3000/ | 学生手机投票 |
| 实时大屏 | http://localhost:3000/screen | 投影实时排名 |
| 管理后台 | http://localhost:3000/admin | 管理操作（默认密码 123456） |

学生手机访问用启动窗口里显示的局域网地址（同一 WiFi）。

## 功能

- **实时大屏**：柱状图 + 排行榜 + 票数走势曲线三区同屏，FLIP 换位动画、舞台光束、金银铜牌、前 10 名晋级区
- **投票页**：手机端卡片式界面，票数实时同步，投票粒子动效
- **管理后台**：选手增删改（可传照片）、投票状态控制、规则设置（每人票数/是否重复投）、模拟投票演示模式、CSV 导出、密码修改
- **外网投票**：支持内网穿透（natapp/cpolar），后台粘贴公网地址即可让微信扫码、手机流量投票
- **防刷票**：设备标记 + IP 限速

## 测试

```bash
node e2e-test.js      # 56 项端到端测试
node test-data.js     # 一键灌入演示数据（约 1400 票）
```

## 技术

零依赖：Node.js 原生 `http` 模块 + SSE 实时推送 + JSON 文件持久化 + 原生前端（纯 CSS 动画，无框架无构建）。数据存于 `data/data.json`，重启不丢。
