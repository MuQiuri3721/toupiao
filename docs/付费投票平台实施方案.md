# 单页产品销售官网实施方案

2026-10-27 用户最新确认的范围，取代先前多页面平台方案。

## 交付
一个首页介绍独立投票系统的用途与功能，展示套餐、价格、功能对比和常见问题。所有购买操作在本页弹窗完成，不制作创建投票、参与投票、结果图表、活动工作台或用户中心。

## 购买与订单
访客选择套餐，填写联系人、联系方式及可选开票信息，服务端根据真实套餐价格生成订单。无需先注册账户。HttpOnly 会话 Cookie 隔离本浏览器订单。我的订单、继续付款、付款申请、取消订单均在首页弹窗内完成。
金额用整数分，订单保存套餐快照。订单状态：待支付、已支付、已取消。取消为终态；确认到账以 SQLite 事务写入已购套餐权益记录，重放不重复入账。独立投票系统的实际交付、开通接口不在本次范围。

## 支付
沿用用户先前要求，微信/支付宝二维码位置预留，未配置时显示待配置，不生成假收款码。用户提交付款申请不等于支付成功，管理员核实到账后确认订单。真实网关回调尚未接入，预留接口拒绝伪造成功通知。需要真实自动支付时再提供商户参数并实现平台验签。

## 管理
首页页脚低调提供订单管理弹窗，通过环境变量配置的管理员密码登录；可编辑套餐与核实订单。不新增后台独立页面。

## 技术与视觉
Node.js 24 原生 HTTP、SQLite、HTML/CSS/JavaScript。灰白 #F6F6F6、雾紫 #8785A2、浅桃 #FFE2E2、柔粉 #FFC7C7，搭配深色正文。ThreeUI Community Gradient CTA、Gradient Pill Button 的独立 HTML/CSS 改编，不引入 React，保留许可证。

## 保留边界
原仓库校园投票文件与 data.json 独立保留，不作为本官网的产品功能入口。新增销售数据库为 data/platform.sqlite。新模块无投票活动/选项/投票记录表或接口。

## 验收
首页与响应式；无需注册直接下单；订单按Cookie隔离；前端不能篡改金额；付款声明不自动确认；支付确认幂等；取消终态；套餐上下架与历史快照；重启持久化；中文分包不乱码；手机购买弹窗可滚动可关闭。
